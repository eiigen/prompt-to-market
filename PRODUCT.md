## Platform

web

## Users

- Solo founders / indie hackers who need a quick launch page + social presence
- Non-designers who want decent AI-generated marketing assets
- Hackathon participants spinning up a product fast

## Product Purpose

Type a product idea → get a launch kit: landing page copy, social media posts, and visual assets — generated by Pollinations AI in seconds. Success means a user goes from idea to a complete, downloadable launch kit in one sitting, without writing copy or opening a design tool.

## Positioning

One input produces a complete, coordinated launch kit (copy + visuals) in parallel in ~60 seconds, with BYOP (Bring Your Own Pollen): users pay their own Pollinations balance, so the developer costs $0 per generation. The claim a copycat could not truthfully make is zero-cost-to-developer AI generation at kit scale.

## Operating Context

- Fully client-side web app hosted on GitHub Pages; no backend, no database, no server costs.
- Users connect Pollinations once via BYOP OAuth (`enter.pollinations.ai/authorize`), then generate freely.
- Past generations persist in the browser for reload; bulk export via JSZip.

## Capabilities and Constraints

Confirmed:

- 10 outputs: positioning statement; landing page copy (headline, subhead, 3 benefit bullets, CTA); Instagram caption; Twitter/X post; LinkedIn post; founder FAQ (5 Q&A); hero image (1200×630); 3 logo variations; social post image (1080×1080); OG image (1200×630).
- Text via `POST https://gen.pollinations.ai/v1/chat/completions`; images via `GET https://gen.pollinations.ai/image/{prompt}`.
- AI-enhanced image prompts (scene/logo/social/OG descriptions) with a fallback to static prompts when enhancement fails.
- History sidebar (fixed on desktop, drawer on mobile); per-output copy/edit/regenerate; download-all as zip.
- No backend — fully client-side. No Stripe/subscriptions — BYOP-only.
- GitHub Pages deployment → HashRouter is mandatory.
- Generated images are stored as data URLs in IndexedDB (`ptm_images` DB) via `src/lib/imageStore.ts` — **not** localStorage.

## Product Principles

1. **Zero-cost to developer** — BYOP makes generation free for the operator; never introduce a backend or billing path that breaks this.
2. **Speed of value** — the full kit in ~60 seconds, generated in parallel; every output is copyable or downloadable in one click.
3. **Client-side by design** — no backend, no database; persistence is browser-local only.
4. **AI-forward but readable** — prompts are engineered for real-world visuals, with static fallbacks when enhancement fails.
5. **Accessibility is part of quality** — interactive elements carry aria-labels; polish must not regress it.
